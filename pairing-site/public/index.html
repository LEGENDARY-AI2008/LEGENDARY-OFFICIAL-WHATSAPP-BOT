🖥️ Panel DeploymentDeploy using a hosting panel

☁️ Render DeploymentDeploy on Render
⌄
  1. Create a new empty GitHub repo with just two files: package.json (with "start": "node index.js") and index.js — paste the code below into that index.js.
  2. Edit the config values at the top, same as the Panel method.
  3. On Render, create a new Web Service from that repo. Build Command: npm install. Start Command: npm start.
  4. Deploy — it'll clone the real bot and start automatically.

🗄️ VPS DeploymentDeploy on your own VPS
⌄
  1. SSH into your VPS, make a folder, and run npm init -y inside it.
  2. Create index.js with nano index.js, paste the code below, edit the config, save.
  3. Run node index.js. Use pm2 start index.js instead if you want it to keep running after you disconnect.
